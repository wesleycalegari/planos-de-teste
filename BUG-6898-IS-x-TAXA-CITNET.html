2. Descrição
Problema reportado (ReproSteps do card):
O CITNET não estava considerando o cálculo de IS (Imposto Seletivo) × TAXA nas prévias do módulo Nacional para a seguradora Fairfax. O processo de prévia estava parado para o segurado ANDORINHA TRANSPORTADORA LTDA (CNPJ 46.435.293/0001-30), com faturamento impactado.
⚠️ Nuance importante: Comentário de Ricardo Lopes (13/05/2026) indica que as evidências enviadas pelo cliente mostravam o cálculo de arredondamento batendo corretamente, sem erro aparente. Foi solicitado aprofundamento. Isso sugere que o bug pode ocorrer em cenário específico — não em toda e qualquer prévia. Os testes devem incluir variações de valor para cobrir essa possibilidade.

Solução implementada: task filha 6925 (Done) — correção do cálculo IS × TAXA nas prévias.
Status dos testes: tasks 6997 e 7090 (Teste HML) estão To Do — este plano cobre essa etapa.
Evidências no card: 4 screenshots de referência + "Evidências Erro CITNET IS X TX (2).docx" + 2 arquivos ZIP com consultas SQL — disponíveis como anexos no AzDO card 6898.
