2. Descrição

Ao realizar a troca de grupo de um usuário já existente na seguradora KOVR, o sistema exibe mensagem de sucesso informando que a alteração foi concluída. Porém, ao consultar novamente o cadastro do usuário, o grupo permanece inalterado — a atualização não está sendo gravada na base de dados.

Bug: a mensagem de sucesso é exibida antes/independentemente de a gravação realmente ocorrer, levando o operador a acreditar que a alteração foi efetivada quando na verdade não foi.

Task de desenvolvimento: Task 7013 — Análise e desenvolvimento (Done).

3. Escopo

In scope:

  • Alteração de grupo de usuários já cadastrados na KOVR
  • Persistência do novo grupo após salvar
  • Exibição correta da mensagem de sucesso apenas quando gravação for efetiva
  • Diferentes perfis e grupos disponíveis na KOVR
  • Regressão — demais operações de cadastro e edição de usuários não afetadas

Out of scope:

  • Criação de novos usuários (apenas alteração de grupo)
  • Gestão de usuários de outras seguradoras
  • Permissões por funcionalidade (apenas grupo/perfil de acesso)

5. Casos de Teste

GRUPO 1 — Alteração de Grupo (Fluxo Principal)
CT-USR-001 P1 Bloqueante Alterar grupo de usuário existente e verificar persistência na base Pré-condições Ambiente: HML KOVR. Conta com perfil Gestor autenticada. Existe usuário cadastrado com grupo definido. Existe pelo menos um grupo diferente disponível. Dados de entrada Usuário-alvo: ⚠️ a confirmar. Grupo atual: ⚠️ a confirmar. Novo grupo: ⚠️ a confirmar. Passos
  1. Acessar https://kovr-hml-faturamento.nsseg.com.br/Login e autenticar com ADMCIT / MSTCIT (conta Gestor confirmada)
  2. Navegar para /Seguranca/UsuarioCIT — módulo Segurança carrega com menu: Usuário CIT | Consulta | Fechar
  3. Localizar o usuário-alvo e abrir para edição
  4. Anotar o grupo atual do usuário
  5. Alterar o campo "Grupo" para um grupo diferente
  6. Clicar em "Salvar" / "Gravar"
  7. Observar a mensagem exibida pelo sistema
  8. Sair da edição e reabrir o cadastro do mesmo usuário
  9. Verificar o campo "Grupo" na consulta do usuário
Resultado esperado O campo "Grupo" exibe o novo grupo selecionado ao reabrir o cadastro. A alteração persiste na base. Tipo Positivo
CT-USR-002 P1 Bloqueante Mensagem de sucesso só aparece quando a gravação é efetivamente realizada Pré-condições Mesmas do CT-USR-001. Sistema com a correção da task 7013 aplicada. Passos
  1. Realizar a alteração de grupo conforme CT-USR-001 (passos 1 a 6)
  2. Verificar se mensagem de sucesso é exibida pelo sistema
  3. Confirmar persistência do grupo (passos 8 e 9 do CT-USR-001)
  4. Comparar: a mensagem de sucesso aparece APENAS quando o grupo está realmente gravado
Resultado esperado Mensagem de sucesso ("alteração realizada" ou equivalente) é exibida. O grupo persiste ao reabrir. Nenhuma mensagem de sucesso deve aparecer sem que a gravação tenha ocorrido. Tipo Positivo
CT-USR-003 P1 Bloqueante Alterar grupo do mesmo usuário mais de uma vez (sequência) Pré-condições Usuário existente com grupo definido. Ao menos dois grupos alternativos disponíveis. Passos
  1. Alterar grupo para "Grupo B" e salvar → verificar persistência
  2. Reabrir o mesmo usuário
  3. Alterar grupo para "Grupo C" e salvar → verificar persistência
  4. Reabrir o mesmo usuário
  5. Alterar grupo de volta para "Grupo A" original e salvar → verificar persistência
Resultado esperado Em todas as iterações, o grupo salvo persiste corretamente ao reabrir o cadastro. Tipo Positivo / Limite
GRUPO 2 — Regressão de Processos de Usuário
CT-USR-004 P2 Importante Demais operações de cadastro de usuário não são afetadas pela correção Pré-condições Ambiente HML KOVR. Conta com perfil Gestor autenticada no módulo Segurança (/Seguranca/UsuarioCIT). Passos
  1. Verificar que é possível consultar usuários existentes (listagem)
  2. Verificar que é possível editar dados de um usuário (nome, email ou similar — campos além do grupo)
  3. Verificar que é possível ativar/inativar um usuário (se a funcionalidade existir)
  4. Verificar que as permissões de acesso de um usuário são exibidas corretamente
Resultado esperado Todas as operações de usuário funcionam normalmente, sem impacto pela correção de grupo. Tipo Regressão
CT-USR-005 P2 Importante Alterar grupo em diferentes perfis disponíveis na KOVR Pré-condições Existência de ao menos 3 grupos/perfis diferentes configurados na KOVR. Passos
  1. Para cada grupo/perfil disponível, alterar o usuário-alvo e verificar persistência
  2. Verificar que cada grupo é gravado e exibido corretamente na consulta
Resultado esperado Todos os grupos disponíveis na KOVR podem ser atribuídos e persistem corretamente. Tipo Positivo
CT-USR-006 P3 Desejável Comportamento ao tentar salvar sem alterar o grupo (valor igual ao atual) Passos
  1. Abrir edição do usuário sem alterar o grupo
  2. Clicar em Salvar
  3. Verificar comportamento do sistema
Resultado esperado Sistema salva sem erro ou exibe mensagem informativa adequada. Grupo mantido sem alteração. Tipo Exceção
