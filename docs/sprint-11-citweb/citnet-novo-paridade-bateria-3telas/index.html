Leitura das duas hipóteses (a decisão de qual está correto é de Produtos):

  • Se o atual estiver certo, o novo não aplica prêmio mínimo (nem integral nem proporcional) e não desconsidera averbações de dias suspensos → faturaria a maior.
  • Se o novo estiver certo, o atual está aplicando o prêmio mínimo mesmo quando o prêmio das averbações é maior — o que contraria a própria regra do código (AutorizacaoPreviaController: deveAplicarPremioMinimo = q_avb_cme == 0 || v_pmo_cml <= 0 || v_pmo_cml <= premioMinimoProporcional) → faturaria a menor.

De todo modo é divergência de valor faturável e precisa ser resolvida antes da migração. Recomendo tratar com o time de Produtos e, definida a regra, reexecutar os 4 cenários de PMM (sem embarque · prêmio menor · prêmio maior · proporcional).
