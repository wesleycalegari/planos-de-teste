2. Descrição

Ao processar a Emissão de Fatura Mensal (módulo Interface, Ramo Geral, referência 06/2026), parte das linhas retornava, na coluna “Resultado Interface Fatura”, o erro IDX10703: Cannot create a 'SymmetricSecurityKey', key length is zero, impedindo o envio dos dados à fila (NSConnect / APIEmissaoFatura) e bloqueando a homologação do CNPJ alfanumérico da KEV/KOVR.

Causa raiz (dev, 11/09 — é configuração de pipeline, não código): a release pipeline CITWEB - KOVR - ALFA - HML (track paralelo da homologação de CNPJ alfanumérico) não estava vinculada aos variable groups que a pipeline padrão usa — faltava o grupo que popula JwtSecretKey (Scope: Interface). Com a chave vazia, AuthService.GenerateToken falha ao criar a chave simétrica (IDX10703). O Web.KOVR.config versionado tem a chave — a divergência era só na instância publicada /alfa/. Correção: vincular os variable groups à pipeline do track alfa. Registrado como KI-005 em .speckit/known-issues.

3. Escopo

In scope

  • Reprocessar em HML /alfa/ as linhas que falhavam (ref. 06/2026, Ramo Geral) e confirmar sucesso, sem IDX10703.
  • Confirmar a entrega efetiva à fila (NSConnect) — não apenas ausência de erro na tela.
  • Regressão: linhas já processadas com sucesso não são impactadas.
  • Documentação do processo de configuração do track /alfa/ para futuras homologações.

Out of scope

  • Alteração de código do módulo Interface — o fix é de configuração de pipeline/deploy.
  • Produção — QA não testa em PROD (N/A).
