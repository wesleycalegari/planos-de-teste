2. Descrição

Na tela Exclusão de Pacotes (InterfaceSTREITI), o combo Estabelecimento (Select2) não carrega opções no ambiente Fairfax, que é publicado sob um path virtual extra (/alfa/InterfaceSTREITI/…). A chamada AJAX que popula o combo é montada com a URL errada e retorna 404 (página de erro HTML), fazendo o JSON.parse falhar.

Causa raiz (confirmada no código): CommonApplication/Scripts/util.js:527, função urlpathname2() assume que o 2º segmento do path (window.location.pathname.split('/')[1]) é sempre o nome do site. No Fairfax (/alfa/InterfaceSTREITI/…) ela pega 'alfa' e perde o segmento real do site (InterfaceSTREITI), então a chamada AJAX vai para uma URL inexistente (404). Consumidor observado: InterfaceSTREITI/Scripts/InterfaceSTREITI/PacoteExclusao.js. DoD prevê corrigir urlpathname2() ou substituir por uma base URL renderizada no servidor (ex.: Url.Content("~/")).
Nota de fase: card novo (fix ainda não deployado no Fairfax). Os caminhos de menu seguem a estrutura do card (InterfaceSTREITI → Pacotes WI → Exclusão de Pacotes); os labels exatos e a validação do fix são confirmados in loco na execução (pós-deploy), com evidência por CT. Sem dados sensíveis: nenhum CNPJ/credencial neste plano público.
