CT-RES-001 P1 Prévia — Relação de Embarques Simplificada RCV com colunas corretas
Aprovado

CA-01  |  PBI #7137  |  RelatorioPreviaDomain → checkbox indRelacaoEmbarquesSimplificada

Positivo — fix principal (Prévia)

P1

Apólice ramo 59 com ao menos 2 averbações fechadas na referência de competência escolhida. Os campos c_id_vgm, v_cml_pmo_vgm e v_qtd_avb devem estar preenchidos na tabela tb_cme_avb_rcv_cit (confirmar via query SQL se necessário).

  1. Acessar CITWEB HML e autenticar.
  2. No menu, navegar até Conta Mensal → Prévia.
  3. Preencher os filtros: selecionar a apólice RCV (ramo 59) e o período de referência com averbações fechadas.
  4. Marcar o checkbox Relação de Embarques Simplificada (indRelacaoEmbarquesSimplificada).
  5. Clicar em gerar / visualizar o relatório.
  6. Abrir o relatório gerado (Excel ou tela).
  7. Localizar as colunas Documento, Valor do Prêmio e Qtde Embarques.
  8. Comparar os valores com os dados da tabela tb_cme_avb_rcv_cit para a apólice e referência escolhidas.

O relatório exibe uma linha por averbação RCV com os campos preenchidos corretamente:

  • Documento = valor de c_id_vgm da respectiva averbação
  • Valor do Prêmio = valor de v_cml_pmo_vgm
  • Qtde Embarques = valor de v_qtd_avb

Nenhum campo deve aparecer em branco, zerado ou com dado de outra tabela.
