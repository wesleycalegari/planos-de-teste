Síntese dos critérios de aceite
Cenário anterior (bug): ao buscar faturas MITSUI ramo 59 (RCV) na tela de Emissão Fatura Mensal, o campo Qtde Avb aparecia como 0 mesmo havendo averbações — porque o sistema lía apenas a tabela de averbações dos demais ramos (tb_mov_avb_nac_cit), ignorando a tabela RCV (tb_mov_avb_rcv_cit).
  • CA-01: Ao buscar faturas MITSUI ramo RCV (59) para referência com averbações, a grid exibe Qtde Avb > 0 corretamente.
  • CA-02: Ao processar a fatura RCV selecionada, o sistema envia o payload para a fila Nsconnect sem erros e exibe "Fatura enviada, aguarde o processamento."
  • CA-03: O processamento de ramos demais (ex.: 21 — Tr. Nacional) continua sem regressão.
  • CA-04 (contingente ao ambiente MITSUI staging): O Nsconnect (MS10-HML) recebe e confirma o payload RCV com os dados de averbação corretos.

CT-NSC-001 P1 Busca de faturas RCV — grid exibe Qtde Avb correta (fix principal)
Pendente

CA-01  |  PBI #6888  |  Fix: GravaTabelaInterfaceAverbacoes agora lê tb_mov_avb_rcv_cit para ramo 59

Positivo — fix principal

P1 — Bloqueante para processar fatura RCV

Apólice MITSUI ramo 59 com ao menos 1 averbação na referência a usar (validada: apólice 0000000000001, ref. 05/2026). Indicativo EditarDmDcRamo59 ativo.

  1. Acessar CITWEB MITSUI HML e autenticar com ROT_AUTO / •••••• (senha no .env).
  2. No menu principal, navegar até Interface → Emissão Fatura Mensal (ou caminho equivalente visível no menu — validar in loco).
  3. Preencher os filtros: Ramo = RCV (59), Mês/Ano de Referência = 05/2026 (ou referência que contenha averbações confirmadas).
  4. Clicar em Selecionar.
  5. Aguardar carregamento da grid.
  6. Localizar a linha referente à apólice com averbações RCV.
  7. Verificar o campo Qtde Avb na linha.

A coluna Qtde Avb exibe valor ≥ 1 para a apólice RCV que tem averbações no período. Antes do fix o valor era 0 (bug). O valor correto foi validado por Fabiano em HML: Qtde Avb = 1 para apólice 0000000000001 — CORRIGIDO.

CT-NSC-002 P1 Processamento de fatura RCV — envio à fila Nsconnect sem erros
Pendente

CA-02  |  PBI #6888  |  Método Processar → GravaTabelaInterfaceAverbacoes → EnviaDadosParaFila

Positivo — fluxo de processamento

P1 — objetivo final do PBI

CT-NSC-001 executado com sucesso (grid exibe fatura RCV com Qtde Avb ≥ 1). A fatura não deve estar com status i_env = "S" (já enviada); se estiver, usar fatura em estado pendente ou criar nova averbação na referência.

  1. Com a grid da busca RCV carregada (resultado do CT-001), marcar o checkbox da linha da apólice RCV com averbações.
  2. Clicar em Processar.
  3. Confirmar o diálogo de confirmação ("Confirma emissão da(s) Fatura(s) Mensal(ais) assinaladas?") clicando em OK.
  4. Aguardar resposta do sistema.
  5. Observar a coluna Resumo na linha processada.
  6. Observar a coluna Resultado / mensagem de retorno.

A coluna Resumo exibe OK e a coluna de resultado exibe "Fatura enviada, aguarde o processamento." — indicando que o payload foi enviado à fila Nsconnect sem erros de gravação nas tabelas de interface (tb_interface_faturas, tb_interface_averbacoes, etc.).

⚠️ A confirmação de processamento final pelo Nsconnect (MS10) depende do ambiente da seguradora — ver CT-004.
