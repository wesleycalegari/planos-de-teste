⚠️ Defeito REPRODUZIDO — porém a causa raiz é AMBIENTE/DADOS, não código

No AXA alfanum (/alfa/), o Relatório de SLA está totalmente inacessível: o módulo GESTÃO tem 31 links de menu e nenhum "SLA" (nem "Justificativa de SLA"). Como o menu não existe, o produto RCV não pode ser listado/selecionado — reproduzindo o sintoma do card.

No AXA não-alfa (referência), os menus SLA (/Gestao/RelatorioSLA) e Justificativa de SLA (/Gestao/JustificativaSLA) existem normalmente → a funcionalidade existe no código; o que falta é o dado que a habilita no ambiente alfanum.

Conclusão: não é defeito de código do CITWEB — é lacuna de ambiente/dados no banco alfanum do AXA. Encaminhado como correção de ambiente (restaurar/semear a tabela habilitadora).

🐛 Bug Reportado (Voidr — 2026-07-14)

Sintoma: No fluxo de Relatório de SLA do produto RCV (ramo 59) no CITWEB AXA alfanum, o produto não é exibido na aba de listagem de relatórios; o item nunca fica visível e o fluxo não avança.

Erro do teste automatizado (RCVRA-204): Timed out 15000ms waiting for expect(locator).toBeVisible() — locator('table, .grid, form').or(combobox) — element(s) not found (dentro de iframe).

URL base: https://axa-hml-faturamento.nsseg.com.br/alfa/ · Build reportada: V 1.0.260713.1840 · Reprodutibilidade: always

ℹ️ Causa raiz — menu SLA é gated por indicador de existência de tabela

  • O menu SLA é controlado pelo indicador Ind_Existe_tb_jst_atr_mov_cit em Tabelas/Controllers/MenuController.cs:1062 — representa a existência da tabela tb_jst_atr_mov_cit (justificativa de atraso de movimento). Confirmado no mapeamento de indicadores do CITWEB e na cobertura do PBI-7499.
  • No /alfa/ somem os dois menus dependentes dessa tabela: SLA (RelatorioSLA) e Justificativa de SLA (que mantém a própria tabela). No não-alfa aparecem os dois. → a tabela tb_jst_atr_mov_cit não existe no banco alfanum do AXA.
  • Inventário de links de menu (via browser_evaluate): /alfa/ = 31 links, 0 com "SLA" · não-alfa = 33 links, 2 com "SLA".

⚠️ Classificação e recomendação

  • O teste Voidr RCVRA-204 passou em 08/07 e passou a falhar de forma determinística a partir de 14/07 no mesmo ambiente alfanum → a tabela existia e foi perdida (provável refresh/rebuild do banco alfanum entre essas datas).
  • Corroboração: a execução EXEC-001748 (14/07) teve 127 de 151 testes falhando no alfanum (mesmo dia, mesma cadeia do BUG #7755) — sinal de ambiente alfanum incompleto/instável naquele momento.
  • Não é defeito de código do CITWEB — o gating de menu funciona por design (oculta quando a tabela não existe). Recomendação: infra/dev restaurar/semear tb_jst_atr_mov_cit no banco alfanum do AXA; depois reexecutar RCVRA-204 no Voidr para fechar o defect.
