CITNET AXA (alfanum) — Conversor: Processar retorna erro genérico — cobertura completa todos os ramos
🏢 Seguradora: AXA 💻 Sistema: CITNET 🌐 Módulo: Conversor → Processar 📋 Epic: #7283

Defeito

BUG #7752 — Na etapa Processar do Conversor, ao processar averbações convertidas, o backend respondia com a mensagem genérica Erro no processamento dos dados! sem detalhar a causa. O fix isolou o tratamento de erros por registro (try/catch individual no foreach), impedindo que a falha de um registro aborte os demais.

Tela: /alfa/citnet/Conversor/Conversor · Ambiente: axa-hml-faturamento.nsseg.com.br

Ramos cobertos pelo Conversor AXA (8 layouts DB): CIT-AVB-RCT · CIT-AVB-TRN · CIT-AVB-RCA · CIT-AVB-RTA · CIT-AVB-RCV · CIT-AVB-EXP · CIT-AVB-IMP · CIT-AVB-RVI

Escopo expandido — todos os ramos

  • O dev testou o fix com RCTR-C (ramo 54). A cobertura é expandida para todos os 8 ramos suportados pelo Conversor AXA
  • Ramos de maior volumetria no HML (RCT: 6819 / TRN: 6042) recebem prioridade P1
  • Falha intermittent: se Processar completar com sucesso → feedback claro ✓; se falhar → mensagem específica ✓

  • Após login → menu → clicar botão CITNET (SSO) → navegar Averbações → Conversor

  9. Observar a mensagem retornada
