Critérios de Aceite

  • Dado que o município da averbação esteja informado corretamente, quando o sistema realizar a busca da taxa comercial, então deverá localizar a taxa cadastrada para o município informado.
  • Dado que exista taxa comercial cadastrada para o município, quando a averbação for processada, então o sistema deverá retornar o valor correto para aplicação no cálculo do prêmio.
  • O sistema deverá aplicar automaticamente a taxa localizada no cálculo do prêmio da averbação.
  • Caso não exista taxa cadastrada para o município informado, o sistema deverá seguir a regra padrão definida pelo negócio ou apresentar mensagem de validação apropriada.
  • O cálculo do prêmio deverá refletir corretamente a taxa comercial obtida para o município da averbação.
