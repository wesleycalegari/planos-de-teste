Escopo

Bug reportado: No módulo Gestão do CITWEB AXA (ambiente alfa/alfanumérico), ao clicar em Exportar em qualquer relatório, a requisição POST para GerarRelatorio?parametro=GESTAO retorna HTTP 500 e nenhum arquivo é baixado. Em alguns relatórios exibe "Ocorreu um erro inesperado". Reproduzido em 3 execuções consecutivas (Voidr DEF-CNPJ-GESTAO-RELATORIO-500).
⚠️ Indício: O mesmo endpoint com parametro=NACIONAL e parametro=INTERNACIONAL também pode retornar 500 (comentário no código de teste Voidr). O fix deve ser verificado nesses contextos também (CT-GES-006 / CT-GES-007).

Tipo

Positivo · Sanidade · CNPJA-01

Pré-condições
  • Ambiente: AXA CITWEB Alfa — https://axa-hml-faturamento.nsseg.com.br/alfa/
  • Fix do bug #7754 deployado em HML alfa
  • Pelo menos uma apólice ativa no filtro GERAL
Passos
  1. Login em https://axa-hml-faturamento.nsseg.com.br/alfa/ com FRED / DERF
  2. No menu, abrir o módulo Gestão (popup)
  3. Navegar até Relatórios → Relação de Apólices
  4. Definir filtro Tipo Ramo = GERAL
  5. Clicar em Exportar (confirmar "Sim" se solicitado)
  6. Aguardar a resposta do servidor
  7. Verificar via DevTools (Network) que o POST para GerarRelatorio?parametro=GESTAO retornou 2xx
  8. Confirmar que o arquivo foi baixado com sucesso
Resultado Esperado

POST GerarRelatorio?parametro=GESTAO retorna 2xx. Arquivo XLSX/XLS/CSV é baixado para o computador. Nenhuma mensagem de erro exibida na tela.

Contraprova (pré-fix)

Antes do fix: POST retornava HTTP 500 e nenhum arquivo era baixado — confirmado em 3 execuções Voidr (EXEC-001731 → 001732 → 001733).
