CITNET AIG — Conversor RCTR-C: FormatException no layout DRK LOG (35 colunas)
🏢 Seguradora: AIG 💻 Sistema: CITNET 📦 Módulo: Conversor → RCTR-C (ramo 54) 🔧 PR: #1803 (feature/cnpj_alfanumerico)

✅ Fix Aplicado

Causa raiz: CitNetServiceNac/ConversorNacionalService.cs · ProcessaLinha_Aig · case 54 (RCTR-C)

Quando o layout do cliente não inclui a coluna v_is_cnn_rcf (layout "DRK LOG", 35 colunas em vez de 36), os campos seguintes do bloco de CT-e são lidos uma posição adiantada no array. O campo c_cdd_dst recebe "C" (tipo de documento) e int.Parse("C") lança FormatException → HTTP 500 / modal "Erro no processamento dos dados!"

Fix: deslocamento dinâmico calculado por dados.Length: 37 = layout sem v_is_cnn_rcf → offset aplicado; 38 = layout completo → comportamento original preservado.
