CT-DMC-001 Averbação via integração — DM/DC persistido da tb_apo_cob_lmr P1 PENDENTE ▶
Pré-condições:
  • Deploy HML Mitsui com fix aplicado (task #7686 Done)
  • Apólice Nacional RCV Mitsui com limites DM e DC configurados na tb_apo_cob_lmr
  • Acesso ao CARGACITNETNAC HML ou mecanismo de envio de carga (API / SQL simulado)
  • Acesso SQL ao banco HML para verificar tabelas

Objetivo

Verificar que ao processar uma averbação via integração CARGACITNETNAC, o sistema busca os valores de DM/DC da tb_apo_cob_lmr vigente e os persiste na tb_mov_avb_rcv_cit.

Passos

  1. Via SQL HML, anotar os valores atuais de DM e DC da apólice de teste: SELECT * FROM tb_apo_cob_lmr WHERE u_id_apo = <id_apo>
  2. Enviar uma carga de averbação para o CARGACITNETNAC referenciando a apólice de teste (via API de integração ou INSERT simulado)
  3. Aguardar o processamento da carga (verificar log ou status de processamento)
  4. No CITWEB Mitsui HML, navegar para: Nacional > Averbação > RCV
  5. Pesquisar a averbação recém-criada pela apólice de teste
  6. Verificar que os campos DM e DC exibidos na tela correspondem aos valores anotados no Passo 1
  7. Via SQL HML, confirmar: SELECT f_vlr_lmt_dm, f_vlr_lmt_dc FROM tb_mov_avb_rcv_cit WHERE u_id_mov_avb = <id_gerado>
  8. Confirmar que os valores na tabela são iguais aos da tb_apo_cob_lmr vigente

Resultado Esperado

Averbação gerada via CARGACITNETNAC exibe DM/DC correspondentes ao limite vigente na tb_apo_cob_lmr no momento da inclusão. Valores confirmados via SQL na tb_mov_avb_rcv_cit.

Critério de Aceite

CA: "Dado uma nova averbação via integração, quando os valores de DM/DC forem buscados, então devem vir da tb_apo_cob_lmr vigente e ser persistidos na tb_mov_avb_rcv_cit."

CT-DMC-002 Movimento aberto — exibe DM/DC históricos sem recalcular P1 PENDENTE ▶
Pré-condições:
  • Averbação criada via CT-DMC-001 com DM/DC históricos registrados
  • Acesso de gestor no CITWEB Mitsui para alterar cadastro de limites da apólice

Objetivo

Verificar que ao consultar uma averbação já gravada (movimento aberto), o sistema exibe os valores de DM/DC da tb_mov_avb_rcv_cit — e NÃO recalcula com o cadastro atual da apólice.

Passos

  1. Anotar os valores de DM/DC da averbação criada no CT-DMC-001 (da tb_mov_avb_rcv_cit)
  2. No CITWEB Mitsui, alterar os limites de DM e DC no cadastro da apólice para valores diferentes (ex: aumentar em 50.000)
  3. Retornar para Nacional > Averbação > RCV
  4. Pesquisar a averbação criada no CT-DMC-001 (mesmo movimento)
  5. Verificar que os valores DM/DC exibidos são os originais (do momento da inclusão), não os novos valores do cadastro
  6. Via SQL confirmar que tb_mov_avb_rcv_cit mantém os valores originais

Resultado Esperado

Averbação exibe DM/DC históricos inalterados, mesmo após alteração dos limites no cadastro da apólice. Integridade histórica preservada na tb_mov_avb_rcv_cit.

Critério de Aceite

CA: "Dado um movimento aberto já gravado, quando o usuário consultar a averbação, então os valores exibidos devem vir da tb_mov_avb_rcv_cit e não devem ser recalculados a partir do cadastro atual."

CT-DMC-003 Integridade histórica — novas averbações usam limite atualizado P1 PENDENTE ▶
Pré-condições:
  • CT-DMC-002 executado — apólice com limite DM/DC alterado
  • CARGACITNETNAC disponível para envio de nova carga

Objetivo

Verificar que averbações incluídas após a alteração do cadastro da apólice usam o novo limite de DM/DC, enquanto as averbações anteriores mantêm o histórico.

Passos

  1. Com os limites DM/DC alterados no CT-DMC-002, enviar uma nova carga de averbação via CARGACITNETNAC para a mesma apólice
  2. Aguardar o processamento
  3. No CITWEB, pesquisar a nova averbação
  4. Verificar que os valores DM/DC desta averbação correspondem ao novo limite do cadastro
  5. Comparar lado a lado: averbação antiga (CT-DMC-001, valores originais) vs. nova averbação (novos valores)
  6. Via SQL: confirmar que tb_mov_avb_rcv_cit armazena valores diferentes para cada averbação conforme o momento de inclusão

Resultado Esperado

Nova averbação usa o limite atual (alterado). Averbação antiga mantém o valor histórico. Separação temporal confirmada na tb_mov_avb_rcv_cit.

Critério de Aceite

CA: "Dado uma alteração posterior no limite da apólice, quando novas averbações forem incluídas, então elas devem usar o novo limite, mantendo as anteriores com o valor histórico."
