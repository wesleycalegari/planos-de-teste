Tipo

Reteste — Verificação de comportamento atual (bug pode ser código ou infraestrutura)

Pré-condições

  • AXA CITWEB HML alfanum acessível: https://axa-hml-faturamento.nsseg.com.br/alfa/
  • Credenciais: FRED / DERF (padrão AXA CITWEB)
  • Módulo Internacional habilitado para o usuário FRED no ambiente alfanum
  • Dados válidos de apólice RCTR-VI (produto, filial, segurado, datas de vigência, IS, moeda)

Passos

  1. Acessar https://axa-hml-faturamento.nsseg.com.br/alfa/ e fazer login com FRED/DERF
  2. Verificar que a tela inicial carrega normalmente (menu superior visível)
  3. Navegar via menu: Internacional → Apólice → RCTR-VI
  4. Capturar screenshot do formulário vazio (EV1 — estado inicial)
  5. Preencher os campos da apólice RCTR-VI: produto, filial, segurado, vigência, importância segurada, moeda
  6. Capturar screenshot com formulário preenchido (EV2)
  7. Clicar em Salvar
  8. Aguardar até 20s pela mensagem de confirmação
  9. Capturar screenshot do estado após o clique Salvar (EV3)
  10. Verificar via browser_evaluate: document.querySelector('iframe')?.contentDocument?.body?.innerText — verificar se contém "Inclusão dos dados efetuada"

Critério de Aceite

✓ SE mensagem aparece: BUG CORRIGIDO — sistema funciona corretamente
✓ SE mensagem NÃO aparece: BUG PERSISTENTE — documentar screenshot + texto da iframe
✓ Em qualquer caso: registrar se a tela carregou corretamente antes do Salvar (diagnóstico ambiente vs código)
