  2. Verificar que a tela inicial carrega normalmente (menu superior visível)
  3. Navegar via menu: Internacional → Apólice → RCTR-VI
  4. Capturar screenshot do formulário vazio (EV1 — estado inicial)

  7. Clicar em Salvar
  8. Aguardar até 20s pela mensagem de confirmação

✓ SE mensagem aparece: BUG CORRIGIDO — sistema funciona corretamente
✓ SE mensagem NÃO aparece: BUG PERSISTENTE — documentar screenshot + texto da iframe
✓ Em qualquer caso: registrar se a tela carregou corretamente antes do Salvar (diagnóstico ambiente vs código)
