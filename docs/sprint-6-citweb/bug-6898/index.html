2. Descrição
Problema reportado:
O CITNET não estava calculando o IS (Imposto Seletivo) × TAXA corretamente nas prévias do módulo Nacional para a seguradora Fairfax. O processo de prévia estava parado para o segurado ANDORINHA TRANSPORTADORA LTDA (CNPJ 46.435.293/0001-30), impactando o faturamento.
Nuance importante: Comentário de Ricardo Lopes (13/05/2026) indica que as evidências do cliente mostravam o cálculo de arredondamento batendo corretamente. Isso sugere que o bug pode ocorrer em cenário específico — os testes devem incluir variações de valor para cobrir essa possibilidade.

Solução: task filha 6925 (Done) — correção do cálculo IS × TAXA nas prévias.
Deploy HML: confirmado por Ricardo em 22/05/2026 — pronto para execução dos CTs.
Evidências no card: 4 screenshots + "Evidências Erro CITNET IS X TX (2).docx" + 2 ZIPs com consultas SQL — disponíveis como anexos no card 6898.
