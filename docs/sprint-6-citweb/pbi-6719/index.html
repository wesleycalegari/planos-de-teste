2. Descrição

A apólice KOVR possui um campo "Cancelamento" (data) no formulário de DadosApólice. Quando o usuário preenchia esse campo com o último dia do mês e existia ao menos uma fatura emitida para aquela competência, o sistema bloqueava a gravação — exigindo o cancelamento prévio da fatura. O comportamento esperado é que o sistema aplique a mesma lógica de regra de 24 horas já utilizada no Relatório de SLA e no Relatório de Análise de Produção, permitindo o preenchimento da data de cancelamento sem bloquear por fatura.

Regra de negócio: a lógica de 24h já existe nos relatórios (SLA e Análise de Produção). A correção das tasks 6821 (Desenvolvimento — Done) + 6932 (Correção do Relatório Análise de Produção — Done) estende essa mesma lógica para o campo data de cancelamento da apólice (CITWEB → Nacional → Cadastros → Apólice → campo "Cancelamento:" no iframe DadosApólice).
3. Escopo
✅ In Scope ❌ Out of Scope
• Cancelamento no último dia do mês COM fatura fechada na mesma competência
• Cancelamento em data que NÃO é o último dia (comportamento preservado)
• Cancelamento sem fatura emitida na competência
• Cancelamento com múltiplas competências faturadas
• Regressão — outros cenários de cancelamento não afetados 		• Cancelamento por motivos não relacionados a data/fatura
• Cancelamento em outras seguradoras
• Relatório de SLA e Análise de Produção (já funcionavam antes)
Ramo/seguradora: KOVR CITWEB · Ramo 21 (Transporte Nacional) confirmado como disponível para massa. A regra se aplica a qualquer ramo com faturamento ativo.

Grupo 1 — Cancelamento no Último Dia do Mês (Cenários da CA)
CT-APL-001 Cancelamento de apólice no último dia do mês com fatura fechada → DEVE PERMITIR P1 Bloqueante Positivo
Pré-condições
HML KOVR · FRED/•••••• (senha no .env) · apólice ativa com fatura emitida em algum mês; data de cancelamento = último dia desse mês
Dados de entrada
Data de cancelamento: último dia do mês corrente (ex.: 31/05/2026) · Apólice: 0000000001910 ou outra com fatura na competência
Passos
  1. Acessar https://kovr-hml-faturamento.nsseg.com.br/Login com FRED / •••••• (senha no .env)
  2. Clicar: Nacional → Cadastros → Apólice → Transporte Nacional (Ramo 21)
  3. Aba Consulta: tipo "GERAL" + vigência "TODAS" → localizar apólice 0000000001910
  4. Clicar no ícone de edição para carregar a apólice no formulário
  5. No iframe DadosApolice, localizar campo "Cancelamento:"
  6. Preencher com o último dia do mês corrente via datepicker
  7. Clicar "Atualizar" e confirmar no dialog
  8. Observar se o sistema bloqueia ou permite o cancelamento
Resultado esperado
Sistema permite o cancelamento sem exibir mensagem de bloqueio de fatura. Cancelamento concluído com sucesso.
