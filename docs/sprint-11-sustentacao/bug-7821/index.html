1. Descrição
Bug: No CITNET AIG (/citnetvulnera/), gravar uma Averbação de Exportação retornava POST /AverbacaoInternacional/Gravar → HTTP 500 com exceção não tratada startIndex cannot be larger than length of string, exibida como o modal genérico "Erro no processamento!". A averbação não era salva (nenhum protocolo gerado).
Root cause (triagem + dev): o parse de c_gar_cit_str usava Substring(2) assumindo o formato "XX+código" (prefixo de 2 chars). Quando a string vinha mais curta (ex.: navio informado por texto livre / código não cadastrado em tb_nav_cit), o Substring estourava startIndex > length → HTTP 500. Fix: commit 994c08b7 / PR #1864 em CitNetAverbacaoInt/CLSINTCALC.cs (1 linha — tratamento de comprimento). Mesma família do #7751 (AXA).
Validação do dev (Ivan): teste de regressão isolado 3/3; validação local (IIS + Oracle SIM50B) com Protocolo 8/9 gerado; e em HML real pós-merge (aig-hml-faturamento.nsseg.com.br/citnetvulnera/) reproduzindo os dados exatos do ticket.
2. Critérios de Aceite
  • CA1 — Gravar a averbação de Exportação com o cenário do ticket (navio por texto livre / não cadastrado) NÃO deve retornar HTTP 500 "startIndex cannot be larger than length of string". Deve gravar com sucesso (protocolo gerado) ou exibir mensagem de validação clara e tratada.
  • CA2 — Regressão: gravar uma averbação de Exportação com dados normais (navio cadastrado) continua funcionando e gera protocolo.
