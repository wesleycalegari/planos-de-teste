A STARR precisa que as DUIMPs processadas no módulo Interface WI/STREITI sejam agrupadas pelo CNPJ pai, consolidando as declarações das empresas do mesmo grupo sob o CNPJ raiz, em vez de tratar registro a registro por filial.
