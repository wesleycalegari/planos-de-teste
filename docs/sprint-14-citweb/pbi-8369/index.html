2. Descrição

A seguradora KOVR mudou a marca para KEV Seguros S.A. O sistema já recebeu a troca de nome e logo, mas as URLs de acesso ao CITNET permaneceram com o prefixo kovr. Este card altera as URLs dos três ambientes (DE → PARA abaixo) e atualiza o cadastro do módulo CITNETKEV na plataforma NSSEG (Backoffice → Modulos → CITNETKEV → Editar → Alterar URL → Atualizar — caminho fornecido na descrição do card) para que o redirecionamento da plataforma leve ao novo domínio. Conforme a observação do card, o CITNET tem três vias de acesso: link direto, redirecionamento da plataforma NSSEG e acesso a partir do próprio CITWEB — as três precisam apontar para o novo domínio.

Contrato técnico verificado (medições de 31/08/2026 + wikis do procedimento):
• Baseline da URL antiga: kovr-hml-faturamento.nsseg.com.br/citnet/ responde HTTP 200 (sem redirect) com título exato KEV SEGUROS S.A.- CitNet — nome já rebrandeado, URL ainda kovr. Registro em evidencias/_baseline/medicao-20260831.txt.
• Plataforma NSSEG HML (hmlplataforma.nsseg.com.br) autentica via Keycloak — realm insurance_market (dev.nstech.com.br), client_id=plataforma (verificado em tela em 31/08, frente do PBI-8368; ver features/_navegacao/plataforma-nsseg.md). Realms de STG/PROD: stg_insurance_market / insurance_market (auth.nstech.com.br — wiki "04 - Keycloak plataforma"). Toda URL nova de módulo precisa entrar nas Valid Redirect URIs / Web origins do client, senão o acesso via plataforma quebra.
• Três vias de acesso ao CITNET (obs. do card + .speckit/quality/citnet-login.md): (1) link direto …/citnet com formulário próprio (campos Usuário/Senha, botão "Acessar"); (2) redirecionamento da plataforma (módulo CITNETKEV); (3) SSO a partir do CITWEB — botão CITNET no menu emite JWT e redireciona (POST /Login/Menu/Redirecionar?app=CITNET).
• Credenciais HML (mesma base KOVR/KEV, nenhum dado migra): CITNET legado usuário INTERNO (chaves HML_KOVR_CITNET_USER/_PASS no .env — usuário e senha são case-sensitive); CITWEB operador FRED (HML_KOVR_CITWEB_USER/_PASS). Senhas somente no .env, nunca neste documento.
