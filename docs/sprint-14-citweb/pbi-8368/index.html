2. Descrição

A seguradora KOVR mudou a marca para KEV Seguros S.A. O sistema já recebeu a troca de nome e logo, mas as URLs de acesso ao CITWEB permaneceram com o prefixo kovr. Este card altera as URLs dos três ambientes (DE → PARA abaixo) e atualiza o cadastro do módulo CITWEBKEV na plataforma NSSEG (Backoffice → Modulos → CITWEBKEV → Editar → Alterar URL → Atualizar — caminho fornecido na descrição do card) para que o redirecionamento da plataforma leve ao novo domínio. Em HML o acesso direto pelo link funciona; em STG e PROD o acesso é sempre redirecionado pela plataforma NSSEG (observação do card).
