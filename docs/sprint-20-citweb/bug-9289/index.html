📌 Resumo para Produtos — em linguagem simples; o detalhe técnico está nas seções abaixo

O que o card pede: O card pede que algumas telas do sistema — a consulta de protocolos da Carga e do Processamento (Interface WI/Siscomex) e o Extrair Dados (Importar/Exportar) — confiram o nome de arquivo recebido do navegador e recusem nome fora do esperado, sem mudar o uso normal das telas.

Vamos testar: Vamos conferir duas coisas. (1) O uso normal continua igual: abrir um protocolo da Carga e ver o conteúdo, abrir um arquivo de declarações desprezadas no Processamento e usar o Extrair Dados com os arquivos que a tela aceita. (2) Quando o pedido enviado pelo navegador é alterado para apontar para um arquivo fora do esperado, o sistema recusa e nada é lido. Os valores e as variações usados nesse teste ficam num guia privado, anexado ao card.

Resultado: Ainda não executamos nenhum teste: o card está em desenvolvimento («In Progress») e o desenvolvimento informou no card que a correção foi enviada ao ambiente de testes, mas o card ainda não foi liberado para homologação. Os testes começam assim que o card estiver em homologação.

O que muda para quem usa: Para quem usa as telas normalmente nada muda (as telas são as mesmas). Quem tentar apontar para um arquivo fora do esperado passa a receber uma recusa.

O que precisamos de Produtos:

  • Nada para decidir agora (Bug: sem aprovação de Produtos). Só para ciência: a variante «Ops» do Extrair Dados só será testada se algum ambiente de testes a oferecer no menu; senão, fica fora do escopo, com a medição registrada.
