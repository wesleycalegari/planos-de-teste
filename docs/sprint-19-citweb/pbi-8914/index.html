2. Descrição

Hoje a NSONE é usada só pela Allianz: o CITWEB (tela Cadastro Instalação ATM) consulta os terminais do segurado e envia pedidos de nova caixa, migração e atualização de caixa postal. Para escalar a NSONE a outras seguradoras, o card exige que cada consumidor se autentique por um token (Keycloak) com o seu próprio client. O desenvolvimento entregou o lado do CITWEB: todas as chamadas à NSONE passam a levar o token do client da Allianz; o token é reaproveitado até perto de vencer; recusa (401) faz nova tentativa uma única vez; se não for possível obter o token, a tela mostra uma mensagem amigável e nada é enviado.
