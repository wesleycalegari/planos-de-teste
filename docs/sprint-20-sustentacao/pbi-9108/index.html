2. Descrição

Na tela «Processar Declarações / Adições», quando o operador digita uma data de desembaraço que não existe (no print do chamado, «até» 31/09/2026), o sistema não mostra um aviso: converte a data sem validar e abre a tela de exceção («String was not recognized as a valid DateTime»). O card pede que o sistema exiba um aviso amigável e não processe nada, e que o restante da tela continue igual.
