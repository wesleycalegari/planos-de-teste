1. Descrição
Problema corrigido: No módulo Conversor, o processamento de embarques do ramo RCTR-VI apresentava lentidão extrema que monopolizava o módulo — outros usuários ficavam impedidos de acessar o Conversor durante a execução.

Causa raiz (análise Diego Almeida): Conexões de banco não estavam sendo abertas e fechadas corretamente (apontado por Sandra Venturim no refinamento). O loop de processamento provavelmente mantinha conexões abertas, gerando lock e degradação progressiva.

Fix aplicado: commit 4b9befc, branch feat/7299-lentidao-conversor-vi. PR mergeado para HML em 12/06/2026 (task #7405 Done).

Referência de performance (medições locais do dev, 12/06/2026):
EtapaAntes do fixApós o fix (local)SLA de referência para HML
Importar~5 min~15 s≤ 60 s
Converter~15 min~1 min≤ 3 min
Processar(bloqueante)~50 s≤ 3 min
⚠️ SLA não definido formalmente no card (campo "A PREENCHER" no PBI). Os valores acima são baseados nas medições do dev em ambiente local — usados como baseline de referência. Se o PO definir SLA diferente antes da execução, atualizar este plano.
Margem aplicada: 4× o valor local para acomodar latência de rede e diferença de hardware do HML.

CT-CVR-001 Processar embarques RCTR-VI dentro do SLA de performance P1 PENDENTE ▶
Objetivo
Validar que as 3 etapas do Conversor RCTR-VI (Importar, Converter, Processar) são concluídas dentro do SLA definido e que o sistema não trava durante a execução.
Pré-condições
  1. Ambiente: CITWEB AXA HML com o fix do PBI-7299 deployado
  2. Usuário: ROT_AUTO / T7Jjm6xF
  3. Planilha RCTR-VI disponível (confirmar com Diego Almeida — mesmo volume do teste local)
  4. Cronômetro disponível para medir tempo de cada etapa
Passos
  1. Acessar https://axa-hml-faturamento.nsseg.com.br/login/ e fazer login com ROT_AUTO
  2. Navegar até o Conversor de Arquivos → menu lateral → RCTR-VI (confirmar caminho exato via MCP)
  3. Iniciar cronômetro — selecionar a planilha RCTR-VI no campo de arquivo
  4. Clicar em Importar — aguardar conclusão
  5. Registrar tempo de Importar (deve ser ≤ 60 s)
  6. Selecionar o layout salvo → clicar em Converter
  7. Registrar tempo de Converter (deve ser ≤ 3 min)
  8. Clicar em Processar — aguardar conclusão
  9. Registrar tempo de Processar (deve ser ≤ 3 min)
  10. Confirmar que o resultado exibe Lidos / Aceitos / Rejeitados sem erro de servidor

Importar: concluído em ≤ 60 s, sem timeout ou mensagem de erro
Converter: concluído em ≤ 3 min, resultado com registros listados
Processar: concluído em ≤ 3 min, resultado com Lidos/Aceitos/Rejeitados visível
Sistema não exibe "Erro ao tentar enviar os dados" ou HTTP 500 em nenhuma etapa
