2. Descrição e Contexto
Contexto técnico O relatório de SLA já existe no código do CITWEB e estava disponível apenas em seguradoras de referência (ex.: KOVR, FAIRFAX).
Este PBI ativa o relatório nas demais seguradoras via indicativos de banco e permissões de perfil.
Indicativo de menu: Ind_Existe_tb_jst_atr_mov_cit — quando ativo, exibe o menu Gestão → Relatórios → SLA.
Permissão: TTFGR131 — obrigatória para acessar o relatório.
Indicativo de colunas de prévia: Ind_Existe_tb_mov_cit_jst_atr — quando ativo, exibe status EM PRÉVIA / PRÉVIA LIBERADA e colunas de data.
3. Critérios de Aceite
  • Menu Gestão → Relatórios → SLA visível para perfis com permissão TTFGR131 (indicativo Ind_Existe_tb_jst_atr_mov_cit ativo)
  • Relatório Básico gera Excel para ramo Nacional, Internacional e Geral (período válido, até 6 meses)
  • Status EM PRÉVIA e PRÉVIA LIBERADA PARA O CORRETOR exibidos quando aplicável (com Ind_Existe_tb_mov_cit_jst_atr ativo)
  • Colunas d_inc_emi_prv / d_alt_emi_prv preenchidas em cenário automático e manual de liberação
4. Pré-requisitos
  • Seguradora HML com indicativo Ind_Existe_tb_jst_atr_mov_cit = 1 ativo no banco
  • Usuário com permissão TTFGR131 configurada
  • Apólice com movimentos de faturamento para período de teste
  • Referência de testes: FAIRFAX HML (piloto confirmado via ADO-6298)
