1. Descrição
Funcionalidade implementada: inclusão da coluna Corretor no grid de consulta do módulo Interface > Emissão de Fatura Mensal. A coluna deve exibir o nome da corretora vinculada ao cadastro da apólice e estar posicionada entre as colunas Data Vencto e Segurado / Pagador.

Motivação: solicitação da seguradora Fairfax para facilitar a consulta interna. Implementação replicada para todas as seguradoras (CORE).

Referência Movidesk: #268409
Estrutura do grid confirmada in loco (24/06/2026):

3. Pré-requisitos e Massa de Dados
Navegação para o módulo Interface:
1. Fazer login no CITWEB
2. Na tela inicial (menu de módulos), rolar até o final e clicar no botão Interface (ícone foguete — não confundir com "Interface WI / Siscomex")
3. O módulo abre em nova aba automaticamente
4. Na nova aba, clicar em Emissão de Fatura Mensal no menu superior
5. Preencher Ramo e Referência (formato MM/YYYY) → clicar Selecionar
