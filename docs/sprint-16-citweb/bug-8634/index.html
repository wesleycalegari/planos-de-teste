2. Descrição

No Conversor de Layout (CITNET, tenant AIG), ao selecionar um arquivo e acionar Importar, o sistema retornava HTTP 500 (NullReferenceException no handler de upload — causa: tb_cit_net_param_geral vazia → path_conversor_upload null → .ToLower() em null). O fix deve tornar o upload de arquivo válido bem-sucedido e tratar entradas inválidas com falha amigável, sem exceção não tratada nem página HTML de erro.

Reteste 04/10: o fix #8998 (INSERT da linha AIG + path corrigido para diretório existente) resolve o defeito — o upload lê o arquivo (POST /Conversor/UpLoadFileFromAjax + LerPlanilhaUpLoad = 200) e as bordas são tratadas com mensagem amigável. 0 reproduções de HTTP 500/NullReference em 6 CTs manuais + 18 casos CONVE.
