Riscos e Observações
Em HML, cotações de câmbio podem retornar 0 ou valor de teste — isso é aceito.
O bug é validado pela ausência da mensagem "Erro ao Consultar Cambio!" — valor zero não é falha.
Se não houver apólice de Exportação para o perfil SEGURADO neste ambiente, registrar CT02 como N/A.
