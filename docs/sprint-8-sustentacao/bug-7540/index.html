1. Descrição
Bug reportado: No CITNET EZZE HML, ao acessar Relatórios → Consulta de Averbações, filtrar os dados e clicar em Imprimir com destino PDF, o sistema lança uma LocalProcessingException em vez de gerar o arquivo.
Impacto: O relatório PDF é utilizado para auditoria de averbações por período. A impossibilidade de exportar para PDF bloqueia o processo de conferência mensal.
2. Critérios de Aceite
  • Ao clicar em Imprimir com destino PDF no Relatório de Averbações, o sistema deve gerar o arquivo sem lançar LocalProcessingException.
  • O relatório gerado deve conter os dados filtrados (filial, ramo, apólice, período) de forma legível.
  • A consulta dos dados sem impressão deve continuar funcionando normalmente após a correção.
3. Pré-requisitos
Acesso ao sistema:
SistemaSeguradoraURLUsuárioSenha
CITNETEZZE HMLhttps://ezze-hml-faturamento.nsseg.com.br/citnet/interno11
Massa de dados:
  • Ao menos uma averbação registrada no período de teste (Ramo 54, mês corrente ou anterior)
  • Filial disponível: confirmar via menu Relatórios antes de executar
Atenção: Confirmar que o período filtrado contém averbações antes de tentar imprimir. Relatório vazio pode não acionar o mesmo código de impressão que causa a exception.
