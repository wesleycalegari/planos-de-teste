⚠️ Critério de aceite: Aprovação funcionando corretamente — a consulta com data de competência válida deve retornar os registros para aprovação sem exibir erro de ano.

Resultado da Execução
BUG CONFIRMADO (FAIL)
Perfil INTERNO — Filial 1 SAO PAULO — Competência 06/2026.
Problema 1 — Máscara trunca o ano: ao digitar 062026 no campo Competência, a máscara aceita apenas 3 dígitos para o ano, resultando em 06 / 026 (faltando o "2" inicial). Digitando com barra 06/2026, o ano fica transposto: 06 / 2602.
Problema 2 — Erro ao Consultar: com ano inválido (026), ao clicar em Consultar aparece o dialog "ATENÇÃO! Erro na Consulta de Fechamento de Fatura!", impedindo a aprovação de prévias.
A máscara do campo Competência está configurada para apenas 7 caracteres (MM / YYY) em vez de 8 (MM / YYYY).
