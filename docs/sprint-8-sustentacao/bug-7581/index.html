Comportamento incorreto observado (24/06/2026):
  • Averbação TN: Filial 5555 (VOIDR) · Apólice 333 · Subgrupo 1 · Mínimos obrigatórios preenchidos
  • Observações preenchido com: @#$%<>&"/teste (chars especiais: < > & " /)

Comportamento esperado após fix (CIT-127): O sistema deve adotar uma das abordagens:

  • Opção B — Rejeitar: exibir modal de validação específico impedindo a gravação quando chars especiais são detectados
  • Em ambos os casos: o valor @#$%<>&"/teste não deve ser persistido literalmente no banco
Rastreabilidade: Mesmo defeito de produto documentado no spec NSTech desde 22/05/2026 (CIT-127) — comportamento recorrente/cross-tenant. Confirmado também em ZURICH. Task #7648 implementa a correção.
