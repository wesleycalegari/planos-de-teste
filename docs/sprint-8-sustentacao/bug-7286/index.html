Descrição do Bug
Três problemas identificados na Averbação Importação Definitiva (CITNET AXA Alfa HML):

1. Mensagem cobertura/embalagem indevida: Ao carregar apólice/subgrupo, sistema exibe automaticamente "Informe a Cobertura antes de selecionar a Embalagem" mesmo sem nenhuma ação do usuário (garantia já preenchida: AÉREO ALL RISKS).

2. Câmbio não atualiza: Com data de saída 07/06/2026, campo câmbio permanece em 5,00000 em vez de refletir a cotação correta para a data.

3. Gravação sem câmbio válido: Sistema permite gravar com câmbio incorreto sem qualquer bloqueio.

Apólice/subgrupo usada em HML: 60620261 / 1 — Provisória: 20260001, Filial: 1 SAO PAULO
Critérios de Aceite
1. Ao selecionar apólice/subgrupo, não deve exibir mensagem de cobertura/embalagem automaticamente.
2. Câmbio deve atualizar corretamente para a data escolhida.
3. Sistema deve bloquear gravação quando câmbio = 0,00000 ou inválido para a moeda/data.
Massa de dados HML: Apólice 60620261 (apólice do bug report 60620251 não encontrada em HML), Subgrupo 1 (saldo FOB: 9.999.899,99), Provisória 20260001, Filial 1 SAO PAULO.
