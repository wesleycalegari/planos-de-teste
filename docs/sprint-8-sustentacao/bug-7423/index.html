Contexto do Bug
O bug documenta o impacto de utilizar CNPJ alfanumérico (ex.: 6P4WZ4L2000111) como código de identificação no CITNET AXA. O método ConsultaSeguradoCorretor_Axa fazia Convert.ToDecimal(documentoSegurado), lançando exceção para qualquer CNPJ com letras. A correção (PR #1711) altera o parâmetro para STRING e usa TryParse a jusante.
Itens corrigidos conforme comentário do dev (Fabiano Souza, 16/06/2026):
• Item 4 — ConsultaSeguradoCorretor_Axa: documentoSegurado passa como STRING; segurado alfanumérico agora carrega sem erro.
• Grid tbAut (autorizacao-previaAXA.js): alinhamento de 17 colunas <th>/<td> corrigido.
• Item Albatroz SSO: corrigido mas schema defasado em HML — não testável.
