Descrição do Bug
Ao consultar uma averbação RCV (ramo 59) que foi excluída/cancelada pelo perfil CORRETOR, o sistema exibia o perfil ASSESSORIA em vez de CORRETOR na tela de Consulta de Averbações (Relatórios → Consulta → Nacional).
✓ STATUS DO RETESTE: APROVADO — Bug corrigido
Averbaçāo RCV excluída pelo perfil CORRETOR aparece corretamente com status "Excluída pelo Corretor" na Consulta de Averbações. Perfil ASSESSORIA não é mais exibido incorretamente.

Apólice 19062026 criada no CITWEB ALFA HML vinculada ao usuário CORRETOR (CNPJ 6P4WZ4L2000111), ramo 59 RCV, filial 1 NSTECH. Averbação protocolo 1 criada (CTE 74490001, 19/06/2026, percurso SP→RJ) e em seguida excluída via Excluir, gerando o registro de averbação cancelada necessário para o reteste.
