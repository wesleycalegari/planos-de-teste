2. Descrição do Problema
O banco ALFA (smt-hom-citweb-axa-alfa) não possui câmbio cadastrado para 16/06/2026 na tabela tb_cbi_moe (0 registros para a data). Mesmo assim, o sistema processou a gravação da Averbação de Importação Definitiva e gerou o protocolo 2026177854 sem exibir erro ou bloqueio. O câmbio deveria ser validado antes de permitir a gravação — bug análogo ao #7382 (Provisória) porém no fluxo Definitiva.
Nota sobre o fix da NullReferenceException: o fix original (razão de abertura do #7379) foi confirmado — a tela de Importação-Definitiva carrega normalmente com ASSESSORIA. Porém, durante o reteste, foi identificado um novo comportamento incorreto: ausência de validação de câmbio antes da gravação. Este reteste é REPROVADO pois o critério de aceitação exige que o fluxo completo funcione corretamente.
Bug relacionado aberto: novo bug filho do PBI #7283 criado para rastrear especificamente a falta de validação de câmbio na Importação Definitiva (análogo ao #7382 para Importação Provisória).
