1. Descrição
Bug reportado: No CITNET KOVR HML ALFA, ao gerar o certificado de uma averbação de Exportação, o CNPJ da corretora exibido no certificado é divergente do CNPJ cadastrado no CITWEB para aquela corretora. Documentos fiscais contêm dado incorreto.
Root cause (dev): Método FormatarCpfCnpj duplicado — o fix do #7615 corrigiu a cópia errada. Deploy concluído em CITNET KOVR ALFA HML (build 1708 / Release-16, def 65).
Ambiente: CITNET KOVR HML ALFA · kovr-hml-faturamento.nsseg.com.br/alfa/citnet/ · Usuário: TSTALFA1 (perfil INTERNO)
2. Critérios de Aceite
  • O CNPJ da corretora exibido no certificado de averbação de Exportação deve ser idêntico ao CNPJ cadastrado no CITWEB para aquela corretora.
  • Nenhuma divergência entre o CNPJ do CITNET e o CNPJ do CITWEB.
  • O certificado deve continuar sendo gerado normalmente (sem erros de geração após o fix).
