Contexto do Bug

Root cause (PR #1744): Ao navegar pelo menu do CITNET para "Autorização de Faturamento", a URL não recebia o parâmetro ?tipo=. O controller não tratava a ausência do parâmetro, causando NullReferenceException e HTTP 500 na tela.

Fix: Quando tipo está ausente ou nulo, o controller aplica tipo=N por padrão, carregando a tela "Autorização de Faturamento — Averbações Mensais — Nacional".

⚠️ Atenção — Reprodução do Bug

O bug ocorre especificamente ao abrir a tela pelo menu (sem parâmetro ?tipo= na URL). Acessar diretamente via URL com ?tipo=N não reproduz o cenário original. Todos os CTs devem navegar obrigatoriamente pelo clique no menu.
