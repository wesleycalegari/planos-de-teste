Descrição do Bug
Causa raiz (crash): Convert.ToDecimal(idUsuario) em ApoliceAccessUtility.cs lançava FormatException quando o CNPJ do usuário logado continha caracteres alfanuméricos (ex.: 6P4WZ4L2000111). Isso derrubava qualquer tela que invocasse o utilitário — incluindo Autorização Prévia e RCTR-C.

Causa raiz (IDOR): O controle de acesso por apólice não separava adequadamente os registros do CORRETOR dos demais usuários — risco de um CORRETOR ver apólices de outros.

Correção: PR #1688 (branch fix/ado-7317-citnet-idusuario-parse-alfa), validado pelo dev Fabiano Souza em 12/06/2026. Introduziu o helper CodigoSessaoConfere() com decimal.TryParse e scoping correto por idUsuario para cada perfil.
