Contexto do Bug

Causa raiz: A tabela tb_tnt_alt_pwd não existia no banco de dados do cliente HDI Global. O HomeController.cs executava SELECT COUNT(1) FROM tb_tnt_alt_pwd WHERE c_org_prd=@c_org_prd AND c_usu=@c_usu AND d_usu_alt>=@d_ref sem verificar se a tabela existia, lançando exceção não tratada que resultava em bloqueio global do sistema — qualquer acesso à tela de login falhava.

Fix aplicado: Adição do indicador Ind_Existe_tb_tnt_alt_pwd em HomeController.cs. O sistema agora verifica a existência da tabela antes de executar a query. Se a tabela não existir, o fluxo de bloqueio por tentativas é ignorado e o login prossegue normalmente. Também corrigidos FormAutentica.cshtml e FormSenha.cshtml para layout centralizado.
