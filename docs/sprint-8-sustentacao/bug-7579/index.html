Contexto do Bug

Causa raiz: A competência é enviada com encoding duplo para EfetuarFechamentoInt — o valor chega como 06%2B%2F%2B2026 (= 06+/+2026 re-encodado) em vez de 06/2026. O backend não tolera o parse e lança System.FormatException → HTTP 500.

Diferença do cluster nacional: para ramos internacionais, ObterResumoFechamentoInt tolera o encoding duplo (Resumo da Fatura abre sem erro), mas EfetuarFechamentoInt não tolera — o erro manifesta-se ao clicar Processar, exibindo modal "Erro na Aprovação de Faturamento!".

Escopo: afeta apenas ramos internacionais (22 Importação/Exportação e 32 RCT-VI). Aprovação de ramos nacionais/RCV não é afetada.

Cluster: mesma causa raiz de BUG-7518 (FAIRFAX), BUG-7521 (MITSUI), BUG-7539 (EZZE), BUG-7545 (STARR) — todos retestados e aprovados. BUG-7579 é a manifestação ZURICH do mesmo defeito.
