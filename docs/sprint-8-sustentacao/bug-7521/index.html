Contexto do Bug

Root cause (PR #1743): A tela de Aprovação de Prévia passava a competência para ObterResumoFechamentoNac sem decodeURIComponent — o valor chegava com espaços codificados (%20) causando FormatException e HTTP 500 ao abrir o modal "Resumo da Fatura". Adicionalmente, a extensão DataTables Buttons não era carregada na grid.

Relacionado a: BUG-7514 (FAIRFAX) — mesma causa raiz, corrigida também em PR #1738.

Pré-condições

Ambiente MITSUI ALFA HML acessível. Credencial CORRETOR/NovaSenha12345!a válida. Fatura no período atual existente.

Passos
  1. Navegar para https://mitsui-hml-faturamento.nsseg.com.br/alfa/citnet/
  2. Fazer login com CORRETOR / NovaSenha12345!a
  3. Confirmar tela inicial carregada (menu superior visível)
  4. No menu, clicar em Faturamento → Aprovação
  5. Aguardar carregamento da tela "Autorizacao de Previa para Faturamento"
  6. Verificar: tela carregou sem modal de erro/HTTP 500 visível
  7. Capturar screenshot da tela
  8. Verificar via JavaScript: document.querySelector('.modal.in')?.style.display
Resultado Esperado

Tela de Aprovação de Prévia carrega completamente sem modal "ATENCAO! Erro na Exibicao do Resumo de Faturamento!" ou qualquer HTTP 500.
