Contexto do Bug
Causa raiz: Usuários da assessoria com CNPJ alfanumérico (contendo letras) causavam erro de conversão SQL varchar → numeric ao carregar qualquer módulo do CITNET. A query de carregamento inicial tentava converter o CNPJ da assessoria para número e falhava.
Escopo do impacto: Todos os módulos de averbação (Nacional e Internacional) e demais telas do CITNET ficavam inacessíveis para o perfil Assessoria quando o CNPJ era alfanumérico.

CNPJ Alfanumérico varchar → numeric
Resultado do reteste: Fix validado. Todos os módulos carregam corretamente sem erro SQL para o usuário ASSESS (CNPJ alfanumérico).
