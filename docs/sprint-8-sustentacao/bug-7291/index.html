Descrição do Bug
Causa raiz: Em FilialRepository.Listar_Por_Segurado_Axa() o CNPJ do segurado era concatenado diretamente na query SQL. Para segurado com CNPJ alfanumérico (ex.: 6P4WZ4L2000111) isso gerava "Incorrect syntax near 'P4WZ4L2000111'", quebrando todas as telas (ex.: Averbação RCTR-C).

Correção: commit d536f7c4 — filtro passou a usar parâmetro @u_cpf_cgc via AddParametro em vez de concatenação de string. Presente no PR #1688 (branch fix/ado-7317-citnet-idusuario-parse-alfa).
Pré-requisitos
Perfil INTERNO: interno / 11
Perfil SEGURADO (CNPJ alfanumérico): usuário 6P4WZ4L2000111 (CNPJ: 6P.4WZ.4L2/0001-11) — não presente no HML DB consultado
URL base: https://axa-hml-faturamento.nsseg.com.br/alfa/citnet/
Tela de teste: Averbações → Nacional → RCTR-C
⚠️ Usuário SEGURADO com CNPJ alfanumérico não localizado no banco HML (tb_cit_net_usu.u_cpf_cgc é coluna FLOAT — não aceita letras).
