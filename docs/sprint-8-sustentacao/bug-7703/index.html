1. Descrição
Bug reportado: No CITNET MITSUI HML ALFA, ao acessar o módulo Conversor de Arquivos, selecionar qualquer layout e clicar em Converter, o sistema retorna imediatamente a mensagem genérica Erro no processamento dos dados!. O módulo é completamente inoperante. O erro ocorre em todos os layouts testados (RCTR-C, Transp.Nacional).
Contexto: Card gerado no reteste do Epic #7283 — Homologação CNPJ ALFA — 03/07/2026. O card original #7523 foi encerrado após o reteste reprovar a correção suposta. Este card documenta o bug persistente e a nova correção aplicada.
Ambiente: CITNET MITSUI HML ALFA · mitsui-hml-faturamento.nsseg.com.br/alfa/citnet/ · Usuário interno (perfil INTERNO) — login sem selecionar filial ("Selecione...").
Root cause (análise do dev): a régua RCTR-C em tb_cit_net_lay_out_pdr (CIT-AVB-RCT) da MITSUI estava sem o campo 26 ("Valor Container RC-DC") — 36 campos em vez de 37. O ProcessaLinha lê por índices fixos (assume 37), então o deslocamento fazia int.Parse("O") (Tipo de Documento lido na posição do Município de Destino) estourar System.FormatException → HTTP 500, exibido como o erro genérico. Fix: INSERT do campo 26 na régua (realinha as posições). Reteste (15/07/2026): régua agora com 37 campos incluindo o campo 26; Converter e Processar retornam HTTP 200 (antes: 500); 1 averbação incluída (Aceitos: 1) com CNPJ alfanumérico válido e 1 linha rejeitada por CNPJ inválido. Bug corrigido.
2. Critérios de Aceite
  • Ao clicar em Converter com arquivo válido para o layout selecionado, o sistema deve processar o arquivo sem retornar Erro no processamento dos dados!.
  • Após conversão bem-sucedida, os registros convertidos devem ser exibidos na tela ou o botão Processar deve estar ativo.
  • Ao clicar em Processar, as averbações devem ser criadas com sucesso.
  • O fluxo deve funcionar para todos os layouts (RCTR-C, Transp.Nacional).
