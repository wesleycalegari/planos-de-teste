Descrição do Bug
Dois problemas na Averbação RCV (CITNET AXA Alfa HML):

BUG 1 — Histórico sem status: Ao excluir um embarque RCV, a Consulta de Averbações não exibe o status do registro excluído (coluna Status fica vazia). Outros ramos (ex.: RCA-C) exibem corretamente "Excluída pela Seguradora".

BUG 2 — Certificado RCV sem Nº do documento: Ao gerar o certificado individual RCV, o campo Nº do documento em Dados da Viagem aparece vazio.

Módulo: Consulta de Averbações — Nacional → RCV
Apólice bug report: 8082028 (histórico) + 6062026 (certificado)
Apólice HML: 333 (c_rmo=59, subgrupo 1) para o histórico | 6062026 para o certificado
Critérios de Aceite
1. Ao consultar o histórico, embarques excluídos RCV devem apresentar status "Excluída pela Seguradora" (ou equivalente), igual ao comportamento dos demais ramos.
2. Certificado individual RCV deve preencher corretamente o campo Nº do documento em Dados da Viagem.
Massa HML: Apólice 333 (RCV, subgrupo 1) para criar/excluir averbação e verificar histórico. Apólice 6062026 (RCV) para gerar certificado. Apólice 8082028 do bug report não encontrada em HML.

CITNET AXA Alfa: https://axa-hml-faturamento.nsseg.com.br/alfa/citnet/
