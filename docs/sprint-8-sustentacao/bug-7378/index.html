O formulário possui três modos de filtragem via radiobutton: Segurado Principal | Ramo/Apólice/Subgrupo | Competência.

Ao selecionar Segurado Principal, o sistema realiza uma chamada AJAX para carregar o dropdown de Segurados. Para o perfil INTERNO, a chamada retorna com sucesso. Para o perfil CORRETOR, a chamada falha e exibe modal "ATENÇÃO! Erro Consulta Segurado!" — impedindo o uso do filtro.

O filtro Ramo/Apólice/Subgrupo funciona corretamente para ambos os perfis.
❌ Bug NÃO corrigido para CORRETOR. O perfil INTERNO foi corrigido, porém o backend ainda retorna erro ao carregar a lista de Segurados via AJAX quando o usuário é do tipo CORRETOR. Card deve retornar para desenvolvimento.
