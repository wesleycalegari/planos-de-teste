Contexto do Bug

Root cause (PR #1743): A tela de Aprovação de Prévia passava a competência para ObterResumoFechamentoNac sem decodeURIComponent — o valor chegava com espaços codificados (%20) causando FormatException e HTTP 500 ao abrir o modal "Resumo da Fatura".

Mesma causa raiz: BUG-7518 (FAIRFAX), BUG-7521 (MITSUI), BUG-7539 (EZZE) — todos corrigidos pelo mesmo PR #1743.

Nota Técnica — Workaround de Execução

O ambiente STARR ALFA apresentou interferência de modal #modal-generic.modal.fade.in bloqueando pointer events após a primeira consulta. O reteste foi executado via JavaScript (element.click(), native value setter para inputs com máscara). Este comportamento não é parte do bug em questão — os resultados refletem o comportamento real do endpoint ObterResumoFechamentoNac.
