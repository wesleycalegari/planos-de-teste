1. Descrição
Bug reportado: No CITNET EZZE HML, ao acessar Averbações → RCTA-C, o dropdown Meio de Transporte exibe opções terrestres (Rodoviário, Rodo-Aéreo) indevidas para o ramo aéreo. Somente AÉREO deveria estar disponível.
Regra de negócio: O ramo RCTA-C (Responsabilidade Civil do Transportador Aéreo de Cargas) cobre exclusivamente o modal aéreo. O dropdown Meio de Transporte deve conter apenas AÉREO, sem opções de modal terrestre.
2. Critérios de Aceite
  • O dropdown Meio de Transporte na averbação RCTA-C deve exibir somente a opção AÉREO.
  • As opções Rodoviário e Rodo-Aéreo devem estar ausentes do dropdown.
  • Averbação RCTA-C com Meio de Transporte = AÉREO deve concluir com sucesso.
