Descrição

Contexto do bug: Quando um CORRETOR realiza o Fechamento de Fatura (Nacional ou Internacional) no CITNET AXA, o campo n_usu_ems (Usuário de Emissão) deveria receber o valor "CITNET" para rastreabilidade. No entanto, os métodos EfetuarFechamentoNacCORRETOR e EfetuarFechamentoIntCORRETOR em FechamentoFaturaController.cs hardcoded o valor como "CITNETL" (com sufixo "L" incorreto), violando os critérios de rastreabilidade.
Atenção — escopo real: O bug NÃO é sobre a tela de Consulta de Averbações. A correção está exclusivamente em FechamentoFaturaController.cs, e o campo n_usu_ems é armazenado apenas no banco de dados — sem coluna correspondente em nenhuma tela do CITNET.

Correção esperada (branch AXA_6927_Emissao): adição de if(indParamGeral) { usuario = "CITNET"; } nos métodos CORRETOR, quando a flag Ind_Param_Geral estiver ativa (AXA).

Critérios de aceite (complemento — Itamar Prado):

  • CA-1: Como corretor, ações na área logada registradas com usuário de emissão "CITNET" (rastreabilidade no BD).
  • CA-2: Campo usuário emissão exibe "CITNET" em TODAS as ações do corretor, sem exceções (Nacional e Internacional).

Observações Técnicas

Arquitetura do campo n_usu_ems:
  • Controller: FechamentoFaturaController.cs — define usuario e passa ao service
  • Service: FechamentoCitNetNacionalService / FechamentoCitNetInternacionalService
  • NSSegApis: SaveApoliceRcaCommandHandler.cs:152 — UsuarioEmissao = f.ExisteUsuarioEmissao ? r.UsuarioEmissao : null
  • Repository: ApoliceRepository.cs:113/149 — INSERT/UPDATE de n_usu_ems quando flag Ind_Usuario_emissao ativa
  • Model: ApoliceCITWEB.cs:95 — public string n_usu_ems { get; set; } — sem uso em nenhuma view
Dois caminhos de autenticação no CITNET AXA:
  • INTERNO: SSO do CITWEB (FRED/DERF). Usa EfetuarFechamentoNac / EfetuarFechamentoInt. Sessão: Session["usuarioCit"].
  • CORRETOR: Acesso direto ao CITNET. Usa EfetuarFechamentoNacCORRETOR / EfetuarFechamentoIntCORRETOR. Sessão: Session["idCNPJCorretor"].

O bug está apenas nos métodos CORRETOR. O fluxo INTERNO não é afetado.
